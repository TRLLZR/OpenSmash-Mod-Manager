components; they are not redistributed in this package. Supported Windows 10
2004+ / Windows 11 x64 include .NET Framework 4.8. A separate modern .NET runtime

contains integration source only, not their downloaded binaries or game content.

the official Microsoft download link and checks local build prerequisites.
