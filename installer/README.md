# OpenSmash Mod Manager

## Quick start

1. Run `Setup.exe` from the extracted installer ZIP and connect your OpenSmash folder.
2. Import ZIP/RAR/7z archives or mod folders, or download through Discover.
3. Review the preview, enable your mods and choose Play with mods.

Pause disables a mod, Undo restores a change, and Play vanilla starts without mods.
For a moveset skin, keep both its base moveset and its visual patch enabled.
Costume skins replace a specific costume; for example, `c01` is the second costume.

Requires 64-bit Windows 10 (2004+) or Windows 11, .NET Framework 4.8+,
PowerShell 5.1 and a complete OpenSmash 13.0.5 installation.
Mod builds also need OpenSmash build inputs, LLVM/Clang,
Microsoft C++ Build Tools and the Windows SDK. The first build can take minutes.
Not every gameplay plugin is compatible. Read the mod author's requirements.

Your game, saves, settings and mod library are kept separate from app upgrades.
Keep backups. Only install mods you trust; do not run downloaded installers/scripts.
