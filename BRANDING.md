# Branding and artwork provenance

`BrandLogo.png` is the horizontal OpenSmash Mod Manager wordmark.
`BrandIcon.png` is the separate orb/sparkle/orbit symbol. `BrandIcon.ico` encodes
that symbol at multiple Windows icon sizes. The former Smash-style icon and the
former wordmark are not part of this publication snapshot.

The maintainer supplied a composite image generated with ChatGPT and requested
that its upper wordmark and lower standalone symbol replace the old assets.
The reported original prompt requested two distinct new images, one with text
and one without, in a Frutiger Aero style with light pastel colors, and asked for
a legally unobjectionable design. Separate transparent assets were then prepared
with the built-in image-editing tool; ICO encoding only changes file format/size.
`BRAND_ASSETS.json` records the source/output hashes and extraction prompts.

These assets are included at the maintainer's request for use with this project
and copies of the application. They are documented separately from the MIT code
license. This repository asserts no separate exclusive copyright or registered
trademark over the AI-generated artwork. Inclusion does not grant rights held by
other people or imply endorsement by another project or company.

An image-generation prompt is not a rights clearance. AI output may resemble
existing material, and copyright protection, trademark rights and the legality
of a particular public use depend on facts and jurisdiction. No trademark search
or legal clearance certificate is supplied. OpenAI's applicable terms govern the
generation service; they are not a license to third-party game art or trademarks.

The name identifies a community manager for an external game project. No Nintendo
character illustrations, game screenshots or official game logo are intentionally
included as branding in this snapshot. Do not suggest an official affiliation.
Fonts such as Trebuchet MS and Segoe UI are used through Windows; font files are
not bundled.
